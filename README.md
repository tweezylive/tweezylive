## 💡 About Me

I'm a 17-year-old developer from Germany. I started coding at 13–14 with Python tools and bots and have since grown into building complete web platforms, from the database to the production deployment.

- 🌐 **Main focus:** Fullstack web applications (Next.js, React, TypeScript, PostgreSQL)
- 💤 **Automation:** Bots, schedulers, webhooks and CI/CD pipelines that remove manual work
- 🧠 **AI:** LLM-powered automations and MCP integrations built into my own tools
- 🛡️ **Security:** Secure-by-default engineering, malware analysis and bug bounty as a second track
- 🗣️ **Languages:** German, English
- 💻 **Programming in:** TypeScript, Python, SQL – currently learning C#
- 🐧 **Environments:** Linux (Arch, Ubuntu, Kali, REMnux) and Windows (10 & 11)
